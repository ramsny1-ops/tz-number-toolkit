# Authoritative sources

The mobile prefix registry in this project was checked against the Tanzania Communications Regulatory Authority National Numbering and Signaling Point Codes Plan, Version 1.16, dated 1 July 2026.

Official TCRA publication index:

https://www.tcra.go.tz/publications/guidebooks

TCRA numbering FAQ, including Mobile Number Portability:

https://www.tcra.go.tz/faq/frequent-asked-questions-on-numbering

The application deliberately reports an original prefix allocation rather than claiming to know a live subscriber's current carrier.
