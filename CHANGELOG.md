# Changelog

## 1.0.0 - 2026-08-31

- Initial full-stack release.
- EJS dashboard.
- Random, sequential and seeded generation.
- Prefix detection and normalization.
- SQLite history and statistics.
- CSV, JSON and TXT export.
- Bulk analyzer.
- Versioned API and core tests.

## 1.1.0 - Cyber dashboard interaction refresh

- Rebuilt the interface around a black glassmorphism design system with white typography, restrained purple interaction accents, and minimal green operational signals.
- Removed all CSS gradients.
- Added animated system status, scan motion, modal transitions, result-row motion, and accessible reduced-motion fallbacks.
- Added SVG navigation and action icons.
- Added a persistent desktop sidebar collapse state plus mobile open and close behavior.
- Added Network Allocation to the sidebar as a modal-first workflow.
- Added a global quick Detector modal while preserving the full detector route.
- Replaced generator network select with a network picker modal.
- Added generation pipeline mimic with spinner and staged process indicators.
- Simplified the welcome dashboard and removed Generated by Network distribution.
- Added Recent Activity and History dashboard cards that open modal tables.
- Preserved full history, allocation, detector, developer, and API routes for deep linking.
